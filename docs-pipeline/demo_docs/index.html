Демо-документы

Синтетический комплект для проверки скрипта: четыре формата, одна задача. Скачайте файлы в одну папку и запустите конвейер — результат совпадёт с выводом на странице кейса.

  • счёт_1042.pdfСчёт на оплату, текстовый PDF — читается pdfplumber PDF ↓
  • акт_88.docxАкт оказанных услуг — читается python-docx DOCX ↓
  • накладная_551.xlsxТоварная накладная — читается openpyxl, ячейки таблицы XLSX ↓
  • скан_письмо_7.pngФото письма — распознаётся Tesseract (rus + eng) PNG / OCR ↓
  • свод_документов.xlsxГотовый результат конвейера — как выглядит выход Excel ↓

Как прогнать самому. Скачайте четыре документа в одну папку, возьмите doc_pipeline.py со страницы кейса и запустите:

python doc_pipeline.py папка_с_файлами — обработать свои документы
python doc_pipeline.py папка_с_файлами --demo — сгенерировать этот же комплект заново
python doc_pipeline.py --ocr — проверить, настроен ли Tesseract

Все данные в файлах вымышлены: компании, номера, ИНН и суммы придуманы для теста. Чужих документов в кейсе нет.
