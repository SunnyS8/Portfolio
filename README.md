# Портфолио — Александра Сарычева

Статический одностраничный сайт-портфолио (продуктовый аналитик / маркетолог-аналитик).

- **Стек:** HTML + CSS + vanilla JS (без сборки).
- **Деплой:** GitHub Pages (user-pages, репозиторий `<username>.github.io`).

## Локальный запуск
```bash
cd SunnyS8.github.io
python -m http.server 5500
# открыть http://localhost:5500
```

## Публикация на GitHub Pages
1. Создать репозиторий `SunnyS8.github.io` (имя обязательно с суффиксом `.github.io`).
2. Запушить содержимое папки в ветку `main`.
3. Настройки репозитория → Pages → Source: `main` / root. Сайт появится по адресу
   `https://sunnyS8.github.io`.

## Структура
- `index.html` — контент (обо мне, опыт, навыки, проекты, open-source, контакты)
- `styles.css` — стили
- `main.js` — подсветка меню и анимация появления
- `.nojekyll` — отключает обработку Jekyll
